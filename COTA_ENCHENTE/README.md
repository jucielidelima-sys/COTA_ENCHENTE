# Dashboard de Risco de Enchente

Atualização da base para INF.COL..xlsx (109 registros).

O app mantém o dashboard original. A planilha está em `base/COTA_ENCHENTE.xlsx`, com todas as 13 colunas originais. O carregamento reconhece Nome, SETOR/POSTO e Acesso empresa.

Execute `pip install -r requirements.txt` e `streamlit run app.py`.

**Privacidade:** a base contém dados pessoais; não publique em repositório público ou em aplicativo sem controle de acesso.
