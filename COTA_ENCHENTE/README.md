# Dashboard de Risco de Enchente — Grupo New Order

Atualização visual com a logo oficial GNO, laranja, branco e grafite. Mantém a base INF.COL..xlsx e as regras operacionais anteriores.

Para atualizar o aplicativo existente no GitHub, substitua `app.py` e adicione `assets/logo_gno.png` e `.streamlit/config.toml`. Mantenha `base/COTA_ENCHENTE.xlsx` no repositório privado.

Execute `pip install -r requirements.txt` e `streamlit run app.py`.

**Privacidade:** a planilha contém dados pessoais. GitHub privado não torna automaticamente privado o aplicativo Streamlit publicado; restrinja também o acesso ao aplicativo.
